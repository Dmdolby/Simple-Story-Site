STORY WEBSITE — HTML & CSS

Files:
index.html — home page and story list
styles.css — shared styles
stories/your-first-story/index.html — story introduction and chapter list
stories/your-first-story/chapters/chapter-1.html — first chapter
stories/your-first-story/chapters/chapter-2.html — second chapter

Open the top-level index.html in your browser. No installation needed.

To add a story:
1. Copy the entire your-first-story folder inside stories.
2. Rename the copied folder to your new story name (use lowercase and hyphens).
3. Edit the title, description, and chapter text.
4. Add a link on the home page to stories/your-new-story/index.html.

To add a chapter:
1. Copy a chapter file inside that story's chapters folder.
2. Give it a new filename and edit its title and text.
3. Link it from that story's index.html and update previous/next links.

Keep all folders together when uploading or moving the site.
The shared stylesheet paths are relative to each HTML page's location.
Editing downloaded files does not automatically change your hosted website.
Ask Sites to update the hosted website when your writing is ready.

The current story and chapters contain placeholder text.
